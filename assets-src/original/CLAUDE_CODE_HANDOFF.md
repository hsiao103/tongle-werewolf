# 數位狼人殺・同樂版｜Claude Code 美術整合交接

## 任務
在**保留現有遊戲架構與規則**的前提下，整合本資料夾的圖片。先盤點技術堆疊、現有頁面、元件、路由、資產目錄及遊戲狀態管理；**不要重建專案**。

## 素材
參見 `manifest.json`。`forest/characters/*-sheet.png` 是角色設定組合圖；`forest/cards/roles-sheet.png` 有五種身分卡（上排左村民、上排右影狼；下排左貓頭鷹、中魔女、右獵人）；`forest/cards/skills-sheet.png` 是四技能（左上查驗、右上救援、左下禁言、右下減票）；`forest/ui/status-sheet.png` 五狀態（上排左存活、中淘汰、右發言中；下排左已投票、右受保護）；`forest/backgrounds/night-dawn-sheet.png` 上半夜晚、下半天亮；`forest/ui/mobile-mockups-sheet.png` 四欄依序是身分揭曉、夜間行動、白天投票、結算。方舟版目前只有主視覺。

## 執行規範
1. 先輸出資產映射表、待裁切清單、整合計畫及影響檔案；不要立即大規模改動。
2. 先建立可回復的 Git commit 或分支，避免覆寫既有功能。
3. 優先直接引用完整主視覺；組合圖需先裁切成獨立圖片並人工檢視，切勿將白底誤認為透明。
4. 需要透明背景時，以合適的影像處理流程去背並檢查邊緣；無法可靠去背時保留原圖並列為待處理，不要偽稱已完成。
5. 圖片使用語意化檔名與集中映射，支援響應式、lazy loading、替代文字及不同螢幕解析度。
6. UI 示意圖只是視覺參考：請用既有元件建立真正可互動的按鈕、狀態、無障礙標籤，不要把整張 UI 圖當成操作介面。
7. 教師私密資訊（身分、夜間操作）絕不可在公開投影顯示；學生端只顯示該玩家被授權的資訊。
8. 遊戲規則與既有 API、WebSocket、房間狀態、投票計算等功能不得因換圖而破壞。
9. 先完成森林版 MVP；方舟版僅預留主題切換，不要假設其他方舟素材已存在。
10. 完成後執行可用的 lint/build/test，提供修改檔案、測試結果、未完成事項與畫面截圖供驗收。
